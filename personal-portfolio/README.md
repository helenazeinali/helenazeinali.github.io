# رزومه شخصی | Cute Pink Portfolio

قالب تک‌صفحه‌ای رزومه شخصی با HTML، CSS و JavaScript خالص.

## اجرا
فایل `index.html` را با مرورگر باز کنید. برای توسعه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## شخصی‌سازی
- نام و معرفی: در `index.html` متن `[نام شما]` و توضیحات نمونه را ویرایش کنید.
- عکس پروفایل: تصویر دلخواه را در `assets/images/` قرار دهید و آدرس `src` تگ تصویر بخش Hero را تغییر دهید.
- خرس ولنتاین: فایل `assets/images/valentine-bear.svg` در دو بخش سایت استفاده شده است.
- مهارت‌ها، خدمات و نمونه‌کارها: محتوای کارت‌ها در `index.html` قابل ویرایش است.
- ایمیل و شبکه‌های اجتماعی: لینک‌های بخش Contact را با اطلاعات واقعی جایگزین کنید.
- رنگ‌ها: متغیرهای ابتدای `css/style.css` را تغییر دهید.

## امکانات
- طراحی فارسی و راست‌چین
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- منوی موبایل
- نمایش تدریجی بخش‌ها هنگام اسکرول
- دکمه بازگشت به بالا
- تصویر پیش‌فرض پروفایل و تصویر اختصاصی خرس ولنتاین
